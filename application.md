### Project Summary
ImpactBags lets anyone launch a **community cause token on Solana in under 60 seconds** using AI — no coding or smart contract knowledge required.

Users describe their cause in one sentence (e.g. “Solar panels for 200 homes in Lagos”), AI generates the token metadata, and one click deploys it via the Bags SDK. Every trade automatically splits fees: **up to 60% goes directly to the cause wallet**, creating sustainable real-world funding from trading activity.

This project strongly aligns with the Solana Foundation’s **Cause-driven building** area while promoting **decentralization** and lowering barriers for Nigerian communities and creators.

### Problem
Communities in Nigeria have pressing needs (clean energy, education, healthcare, etc.) but struggle with traditional fundraising that is slow, expensive, and often centralized. Launching a token is powerful but remains too technical for most organizers and activists.

### Solution
ImpactBags is a Next.js + TypeScript web application that makes cause-based token launches simple and effective:

**Core Flow:**
1. Describe your cause in plain English
2. Claude AI generates name, ticker, description, and viral hook
3. One-click deployment on Solana
4. Automatic on-chain fee splits fund the cause

**Fee Distribution (per trade):**
- Up to 40% → Cause wallet (real-world impact)
- 30% → Token holders (incentivizes community)
- 20% → Creator (sustainability)

**Key Features in MVP:**
- AI token generation (Claude)
- Seamless integration with Bags SDK for deployment
- Real-time dashboard showing funds raised and impact
- Proof-of-impact uploads (photos/receipts)
- Mobile-friendly for Nigerian users
- Built with Next.js, TypeScript, and Solana web3 tools

**Live Prototype:** https://impactbags.vercel.app
